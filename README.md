## 📚 O que aprendi sobre Git e GitHub

Durante esta atividade prática, revisitei os principais conceitos de versionamento e pratiquei os seguintes comandos:

* 🟢 **`git init`**: Inicializa um novo repositório Git local.
* 🟡 **`git status`**: Mostra o estado atual dos arquivos (modificados/salvos).
* 🔵 **`git add`**: Adiciona as modificações à área de preparação (Staging Area).
* 🟠 **`git commit`**: Salva as alterações na linha do tempo com uma mensagem.
* 🟣 **`git push`**: Envia os commits locais para o repositório remoto no GitHub.
