## O que aprendi sobre Git e GitHub

Durante esta atividade prática da WoMakersCode, revisitei os principais conceitos de versionamento e pratiquei os seguintes comandos:

- **git init**: Inicializa um novo repositório Git local na pasta do projeto.
- **git status**: Mostra o estado atual dos arquivos (se foram modificados, adicionados ou se estão fora do versionamento).
- **git add**: Adiciona as modificações dos arquivos à área de preparação (Staging Area), preparando-os para o salvamento.
- **git commit**: Salva permanentemente as alterações na linha do tempo do repositório local, acompanhado de uma mensagem descritiva.
- **git push**: Envia todos os commits realizados no repositório local para o repositório remoto no GitHub.
