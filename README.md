## [cite_start]📚 O que aprendi sobre Git e GitHub [cite: 37, 38]

[cite_start]Durante esta atividade prática, revisitei os principais conceitos de versionamento e pratiquei os seguintes comandos[cite: 8, 40, 42]:

* [cite_start]🟢 **`git init`**: Inicializa um novo repositório Git local[cite: 28, 40, 42].
* [cite_start]🟡 **`git status`**: Mostra o estado atual dos arquivos (modificados/salvos)[cite: 40, 42].
* [cite_start]🔵 **`git add`**: Adiciona as modificações à área de preparação (Staging Area)[cite: 29, 40, 42].
* [cite_start]🟠 **`git commit`**: Salva as alterações na linha do tempo com uma mensagem[cite: 30, 40, 42].
* [cite_start]🟣 **`git push`**: Envia os commits locais para o repositório remoto no GitHub[cite: 35, 40, 42].
